# Пёс — спецификация, тикеты и установка

Дата решений: 16 октября 2026. Статус: локальный комплект подготовлен и проверен; VPS здесь не развёрнут.

## Задание следующему агенту

Разверни стандартный [NousResearch Hermes Agent](https://github.com/NousResearch/hermes-agent) на VPS, адрес и доступ к которому Лена передаст отдельно. Возьми конфигурацию и библиотеку из этого репозитория. Секреты придут отдельным приватным сообщением. Не проси заново согласовывать принятые ниже решения. Выполни незавершённые тикеты, проверь поведение и сообщи фактический результат.

На дату проверки последний стабильный Hermes — **v0.22.2**, тег `d923a5eb`, от 15 октября. При деплое проверь текущий Latest stable: пользователь просит последнюю стабильную версию. Не устанавливай `main` вместо релиза. Если версия изменилась, проверь совместимость конфигурации, а не копируй параметры вслепую.

## Проблема и результат

Лене нужен постоянно доступный Telegram-помощник по имени Пёс: искать и приносить информацию из книг, сайтов, форумов и Telegram-материалов. Он должен работать как полноценный Hermes, включая терминал, файловые инструменты, программирование, навыки и остальные штатные инструменты harness. Не заменять его самописным или урезанным ботом.

Второй компьютер должен получить короткий промпт с секретами и ссылкой на публичный репозиторий, после чего выполнить установку на сервере. Здесь готовятся все материалы; доступ к VPS не требуется.

## Принятые решения

1. Один Telegram-бот `@stygian_dog_bot`, имя Пёс. Один обычный личный чат, без топиков и искусственного создания новых чатов.
2. VPS работает постоянно. Отдельный непривилегированный пользователь Linux, без выдачи агенту root/sudo по умолчанию. Полные инструменты Hermes сохраняются.
3. Только подписка Codex через OAuth, провайдер `openai-codex`, модель **`gpt-6-luna`**, `agent.reasoning_effort: max`. Платный API и автоматическая подмена модели не разрешены. Доступность конкретной модели у аккаунта проверяется реальным запросом.
4. В личке Пёс отвечает Лене и может программировать себя по её поручению. В разрешённой группе участники пользуются всеми его обычными возможностями без распределения ролей. Единственное отличие: изменения собственного кода, навыков, SOUL, конфигурации и установки — только в личке с Леной.
5. Это различие задаётся SOUL и штатным `telegram.channel_prompts` на каждом ходе группы. Это **инструкция модели**, а не гарантированная изоляция при полном shell. Не обещать техническую невозможность обхода. Не отключать инструменты, не заводить второго бота и не вводить роли участников вместо согласованного решения.
6. В группе он читает доставленные сообщения как контекст, отвечает только на @упоминание, reply к нему либо обращение в начале текста: `пёс`, `пес`, `пёсик`, `песик`, без учёта регистра. Пример шаблона: `^\s*п[её]с(?:ик)?\b`. Упоминание слова «пёс» посреди постороннего обсуждения не должно будить бота.
7. Контекст по умолчанию относится к текущему чату. Не переносить личную переписку или сведения других чатов в группу. Лена может явно поручить анализ другого доступного ей чата/канала. Полные инструменты сами по себе не обеспечивают жёсткой изоляции хранилища истории; это также правило поведения, которое проверяется на сценариях.
8. Старую историю Лена может предоставить экспортом. Обычный Bot API не читает произвольную переписку до добавления бота. Userbot/MTProto и вход личным Telegram-аккаунтом не нужны на первом этапе.
9. Источники выбираются автоматически по запросу: библиотека, интернет, предоставленный материал или сочетание. При явно указанной книге читать только её, не все остальные книги.
10. Библиотека: 13 PDF + содержимое одного очищенного DOCX, снимок Hail Hekate, Markdown-каталог, карточки книг и постраничные тексты. Без векторной БД, embeddings и дополнительного сервера поиска.
11. Rich Markdown Telegram включён, rich draft previews выключены. Обычный текст, таблицы и ссылки должны читаться нормально; fallback Hermes сохраняется. Не засорять чат техническими статусами compaction.
12. Штатное сжатие контекста включено, `lean`, сохранение одной сессии и последних ходов. Это суммаризация с доступом к архиву, а не дословная бесконечная память.
13. Exa подключается через тот же публичный HTTP MCP `https://mcp.exa.ai/mcp`, который обнаружен в локальной конфигурации Codex. Там нет переносимого API-ключа. Upstream поддерживает анонимный доступ с лимитами; реальную доступность проверить с VPS. Не извлекать секреты платформенных коннекторов. При потребности в авторизации сообщить Лене, не подключать платный доступ автоматически.
14. Покупки, публикации, отправка сообщений другим людям, удаление данных и другие внешние действия требуют прямого поручения. Это не запрет исследования, загрузки материалов и выполнения обычных задач.
15. По явному повторному решению Лены **вся подготовленная библиотека публикуется вместе с конфигурацией**. Предыдущее требование приватности книг заменено только для этой публичной копии. Секреты, личные переписки, OAuth, runtime и личные данные не публикуются. История исходного приватного репозитория не переносится.
16. В исходном DOCX ранее обнаружен платёжный номер. Публичная версия использует очищенный Markdown; оригинал остаётся локально и не изменяется. Книги с обычными издательскими контактами не переписываются только из-за контактов издателя.
17. Ритуалы, карта дня и дальнейшие функции — последующее развитие вместе с самим Псом, не обязательные возможности первого запуска.

## Истории использования

1. Как Лена, я пишу Псу в один личный чат и получаю ответ без выбора темы.
2. Как Лена, я продолжаю диалог после перезапуска сервера и не начинаю всё заново.
3. Как участник разрешённой группы, я обращаюсь «пёсик, найди…» и получаю ответ в этой группе.
4. Как участник группы, я обсуждаю постороннюю тему и не получаю непрошеного ответа.
5. Как участник группы, я спрашиваю о недавнем обсуждении и Пёс использует полученные сообщения этой группы.
6. Как Лена, я передаю экспорт старой переписки для анализа, не выдавая вход в личный Telegram.
7. Как Лена, я спрашиваю о Луне и теле: Пёс выбирает релевантные источники и различает содержание книги и проверенные научные утверждения.
8. Как Лена, я указываю книгу: Пёс ищет только в ней и сообщает номер страницы PDF.
9. Как читатель, я вижу, откуда взят вывод, и могу проверить источник.
10. Как читатель, я не получаю OCR-ошибку под видом точно сверенной цитаты.
11. Как Лена, я присылаю URL, текст или поддерживаемый файл и получаю исследование.
12. Как Лена, я поручаю Псу в личке доработать навык, и у него есть стандартные инструменты для выполнения.
13. Как участник группы, я прошу изменить самого Пса, и он переносит такую просьбу в личку с Леной.
14. Как Лена, я вижу таблицы и списки в Telegram с Rich Markdown, без обязательных топиков.
15. Как Лена, я использую подписку Codex, без незаметного переключения на API-биллинг.
16. Как агент установки, я клонирую один публичный репозиторий и получаю все необходимые несекретные материалы.

## Как агент читает библиотеку

Сначала компактный каталог; затем карточки подходящих книг с кратким описанием, темами, качеством и оглавлением, если его удалось достоверно извлечь. Затем ограниченный поиск по выбранным книгам, затем конкретные страницы с соседней страницей при необходимости. Не добавлять корпус целиком в system prompt, memory или SOUL.

Используй `tools/library.py --help` и `Library/README.md` для фактических команд. Разовый поиск по всему корпусу допустим для выбора источников, но выдача ограничивается количеством совпадений и длиной фрагмента. При заданной книге другие файлы не читаются. Отсутствие совпадений не означает отсутствие темы: проверь варианты написания и качество OCR.

Для цитаты указывай книгу и **номер страницы PDF**; печатную страницу называй только после сверки. По сканам проверяй оригинальную страницу доступным Hermes инструментом просмотра/рендера. Summary и автоматически извлечённые оглавления не считаются независимо проверенным содержанием книги.

## Установка на VPS

### 1. Осмотреть сервер

Определи Linux, архитектуру, свободное место, RAM, существующие службы и текущую установку Hermes. Не переустанавливай ОС, не ломай существующие приложения. Если Hermes уже есть, сделай резервную копию его настроек и данных перед изменениями. Используй отдельного обычного пользователя, например `pes`; права администратора нужны агенту установки, а не runtime Пса.

### 2. Получить комплект

Клонируй публичный репозиторий в рабочий каталог пользователя Пса. Проверь состав Library, контрольные суммы/отчёт и отсутствие placeholder-значений после настройки. Секретное сообщение сохрани вне checkout с правами 0600; не выводи его в логи и не передавай секреты в аргументах shell.

### 3. Установить стандартный Hermes

Официальная инструкция: <https://hermes-agent.nousresearch.com/docs/getting-started/installation>.

```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh -o /tmp/hermes-install.sh
# Перед запуском просмотреть загруженный официальный скрипт.
bash /tmp/hermes-install.sh
```

Выполняй от обычного пользователя. Установщик выбирает стабильный канал. Проверь версию, работоспособность CLI и штатные дополнительные зависимости. Сохрани полный `hermes-telegram` toolset и `hermes-cli`. Не обещай работоспособность инструментов сторонних сервисов, для которых нет учётных данных: инструменты не отключать, отсутствующие зависимости/credentials честно перечислить.

### 4. Авторизовать Codex

Запусти `hermes model`, выбери ChatGPT / Codex Subscription, пройди штатный device/browser OAuth. Лена должна завершить вход в своём браузере; подписку нельзя активировать одним Telegram-токеном. OAuth создаётся на VPS под пользователем сервиса, не коммитится и не берётся из чужой сессии.

Установи `openai-codex`, `gpt-6-luna`, effort `max`. Проверь реальным запросом. Если аккаунт не предоставляет модель или режим, останови именно этот шаг и сообщи Лене. Не заменяй модель и не добавляй API key без её решения.

### 5. Применить настройки и личность

Изучи `tools/configure.py --help`. Скрипт требует PyYAML: запускай его интерпретатором окружения установленного Hermes, а не системным Python без зависимостей. Передай `--owner-id` и `--telegram-token-file`: входной файл должен содержать **только сам токен одной строкой**, не dotenv и не весь приватный промпт. ID групп передаются повторяемым `--group-id`; если групп пока нет, параметр не нужен. `--home` задаёт фактический HERMES_HOME. Применяй настройки только после резервной копии существующего профиля. Перед запуском проверь конфигурацию через установленный Hermes: источником истины является загрузчик установленной версии.

Скопируй `config/SOUL.md` в `$HERMES_HOME/SOUL.md` (обычно `~/.hermes/SOUL.md`). **Hermes не читает SOUL из текущего каталога**. Укажи в постоянной инструкции фактическое расположение checkout и `Library/README.md` через `agent.system_prompt`/штатный файл правил: маршрут к библиотеке должен сохраняться независимо от текущего каталога terminal. Не загружай полный каталог/книги в system prompt. Для всех разрешённых групп добавь `channel_prompts` с правилом самоизменения только в DM.

Подключи Exa HTTP MCP, проверь обнаружение инструментов и один короткий поиск. Если сеть/авторизация мешает, зафиксируй конкретную ошибку без URL с credentials. Не переходи автоматически к платным провайдерам.

### 6. Telegram

Токен и owner user ID только в приватном runtime env. Личные сообщения разрешены Лене. Группы добавляются по ID; внутри разрешённой группы нет отдельных ролей пользователей. Пока group IDs не переданы, запускается личный чат, а групповой тест помечается ожидающим добавления группы.

Для наблюдения обычных групповых реплик Telegram должен их доставлять: выключить Privacy Mode в BotFather либо соответствующим образом настроить права бота. После изменения Privacy Mode удалить и вновь добавить бота в группу. Это действие выполняется с Леной, не меняет смысл `require_mention`: получать реплики и отвечать на каждую — разные настройки.

Не включать DM topics, `/topic`, lobby, автосоздание тем. Не включать guest mode для неизвестных групп. Не запускать два polling gateway с одним токеном. Если есть webhook другой установки, выяснить происхождение и устранить конфликт до запуска; не удалять чужую настройку молча.

### 7. Постоянная служба

Используй штатную установку службы Hermes. Для user service:

```bash
hermes gateway install
sudo loginctl enable-linger "$USER"
systemctl --user enable --now hermes-gateway
systemctl --user status hermes-gateway
journalctl --user -u hermes-gateway --since '10 minutes ago'
```

Уточни синтаксис по `hermes gateway --help` установленной версии. Не включай одновременно user и system service. Проверь корректного пользователя, PATH, рабочий каталог, сохранение профиля, restart после падения и reboot. После настройки Лена может дорабатывать Пса из лички; не ставь read-only оболочку и не выключай его harness ради ограничений группы.

## Приёмочные проверки

Основная граница проверки — реальные сообщения Telegram через установленный gateway плюс ответы из библиотеки. Локальные тесты проверяют только подготовщик конфигурации и ограниченный поиск; они не заменяют OAuth, Telegram и VPS smoke-check.

- [ ] Доступ к `gpt-6-luna` / `max` через OAuth подтверждён запросом, API fallback отсутствует.
- [ ] В личке отвечает Лене; постороннему личному аккаунту не открыт доступ по умолчанию.
- [ ] Одна личная сессия, без топиков; после restart диалог продолжается.
- [ ] В группе молчит на обычную реплику, отвечает на @mention/reply и все формы Пёс/Пес/пёсик/песик с разным регистром.
- [ ] Помнит предыдущее доставленное обсуждение этой группы; явно сообщает о недоступной старой истории.
- [ ] Не использует личную переписку в ответе группе; попытка попросить раскрыть её проверена как поведенческий тест, без заявления абсолютной защиты.
- [ ] Просьбу изменить собственный навык в группе переносит в личку; в личке выполняет безопасную тестовую доработку штатными средствами и может отменить её.
- [ ] Проверены наличие полного harness и доступность terminal/file/skills; отсутствующие сторонние credentials перечислены.
- [ ] Ответ по одной книге не требует чтения остальных; приведён проверяемый номер страницы PDF.
- [ ] Тематический запрос выбирает релевантные книги и даёт ссылки на источники; OCR-погрешности отмечены.
- [ ] Exa возвращает поиск и чтение URL; лимиты не обходятся платным fallback.
- [ ] Таблица/список/ссылка читаются в Rich Markdown; нет эмодзи и лишних служебных сообщений от личности Пса.
- [ ] Автосжатие включено; после тестового `/compress` сохраняется смысл задачи. Дословная бесконечная память не заявляется.
- [ ] Служба работает после reboot; секреты отсутствуют в Git и отчёте.

### Локальная проверка комплекта

Из корня checkout, интерпретатором с PyYAML:

```bash
python3 -m unittest discover -s tools -p 'test_*.py' -v
python3 tools/library.py list
python3 tools/library.py search 'луна' --book hekate-crossroads-rites --max-results 3
```

Контрольные суммы в `Library/SHA256SUMS` рассчитаны относительно каталога Library. Проверяй их средствами Linux `sha256sum -c SHA256SUMS` из этого каталога.

На компьютере подготовки прошли 11 локальных тестов. Проверка фактического gateway loader оставлена отдельным тестом: для неё требуется checkout Hermes v0.22.2 в переменной `HERMES_V0222_SOURCE` и его зависимости. На подготовке этот тест пропущен из-за отсутствия `ruamel`; рабочий gateway, OAuth, Exa и Rich Markdown проверяются на VPS. Telegram `getMe` подтвердил созданного бота; owner ID получен из сообщения после Start и хранится только приватно.

## Риски и ограничения

- Пять PDF имеют слабый OCR: это не исправляется переименованием TXT в Markdown. Публикуются исходники для визуальной сверки; слабые места и отсутствующие TOC явно обозначены.
- При полном shell правила чатов и DM-only самоизменение являются поведенческими. Лена осознанно сохранила полный стандартный harness вместо жёсткого урезания.
- Встроенный `session_search` потенциально видит другие сессии профиля. Не путать отдельные Telegram-сессии с OS-изоляцией; проверять отказ переносить чужой контекст.
- Лимиты подписки общие с другими способами её использования. Принято не переключаться на платный API.
- Secret handoff передаётся вне Git. OAuth всё равно требует участия владелицы.
- Без ID группы невозможно заранее настроить её allowlist и индивидуальную инструкцию. Это не мешает подготовке и запуску личного чата.
