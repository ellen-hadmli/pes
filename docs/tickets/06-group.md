# Пёс — подключить разрешённую группу (после личного запуска)

**Результат:** Дать участникам группы пользоваться стандартным Псом по обращению, с контекстом этой группы.

**Блокируется:** 05 и ID группы

**Статус:** waiting-for-group

- [ ] Участники не делятся на роли; доступ ко всем стандартным инструментам сохранён.
- [ ] Privacy/delivery настроены, allowlist группы и channel prompt применены.
- [ ] Неадресные сообщения не вызывают ответа; @mention/reply/все русские формы работают.
- [ ] Контекст группы доступен, личные сообщения не переносятся в ответ.
- [ ] Просьба изменить самого Пса перенаправляется в личку с Леной.
