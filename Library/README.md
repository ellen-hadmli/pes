# Библиотека Гекаты для Пса

Локальный корпус для поиска и ответов с указанием источника и страницы. Векторная база и сервер не нужны.

- `CATALOG.md` — список книг и качество извлечения.
- `cards/` — краткие описания, алиасы, OCR-ограничения и оглавления, если их удалось выделить.
- `books/` — PDF-копии.
- `text/` — постраничный Markdown для поиска.
- `site/` — текстовый снимок публичного сайта.
- `REPORT.md` — состояние и ограничения подготовки.
- `library.json` — относительный машинный индекс.

Поиск только в одной книге:

```bash
python3 tools/library.py list
python3 tools/library.py search 'дейпнон' --book hekate-crossroads-rites
python3 tools/library.py show --book hekate-crossroads-rites --page 42
```

`search --all` ищет только по книгам в `text/`, а не по снимку сайта. Сайт ищите отдельно штатным инструментом Hermes `search_files`, ограничив область `Library/site/`, либо через терминал из корня репозитория:

```bash
rg -n -i 'дейпнон' Library/site/
```

Для поиска по всем книгам укажите явный opt-in: `--all`. Цитаты сверяйте по оригинальному PDF; номер страницы поиска — физическая страница PDF.
