# Пёс

Полноценный Hermes Agent Лены для Telegram, работы с книгами и поиска информации.

**Агенту установки: начни с [HANDOFF.md](HANDOFF.md).** Там спецификация, принятые решения, тикеты, порядок установки на VPS и приёмочные проверки. Сервер и секреты Лена передаёт отдельно.

- [Личность Пса](config/SOUL.md)
- [Библиотека](Library/README.md)
- [Тикеты](docs/tickets/)
- [Исследование Hermes](docs/HERMES-RESEARCH.md)

Провайдер: подписка Codex OAuth, модель `gpt-6-luna`, effort `max`. Один личный чат без топиков; в группах — ответы по обращению. Все штатные инструменты Hermes сохраняются. Изменения самого Пса — в личке с Леной.

Статус: локальный комплект подготовлен; развёртывание на VPS выполняет другой компьютер по HANDOFF.md. Наличие файлов не означает, что бот уже запущен. Книги и производные материалы включены по явному решению Лены; секреты и runtime в репозиторий не входят. Отдельной лицензии на распространение книг этот репозиторий не предоставляет.
